### Краткие тезисы презентации:
1. **Проблема обычной маршрутизации:** Заголовки IP-пакетов открыты, трафик и местоположение легко отследить.
2. **Принцип Onion Routing:** Многослойное шифрование. Каждый узел снимает один слой и знает только адрес следующего узла.
3. **Цепочка TOR:** Входной узел (Guard) $\rightarrow$ Промежуточный узел (Middle) $\rightarrow$ Выходной узел (Exit).
4. **Скрытые службы (.onion):** Анонимизируют не только клиента, но и сервер; используют End-to-End шифрование.
5. **Риски и ограничения:** Прослушивание Exit-узлов (при HTTP без TLS), атаки по временным меткам, человеческий фактор.
